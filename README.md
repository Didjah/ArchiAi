# ArchiAI 🏗️

Plateforme de conception architecturale intelligente propulsée par l'IA.

## Fonctionnalités

- Génération automatique de plans architecturaux
- Interface bilingue Français / Anglais
- Entrée texte ou voix
- Partage multi-canal (WhatsApp, Email, Telegram, SMS, LinkedIn, Copier le lien)
- Design professionnel bleu nuit + or

## Stack technique

- HTML / CSS / JavaScript pur
- Claude API (Anthropic) pour la génération de plans
- Déploiement sur Vercel

## Installation

1. Cloner ce repository
2. Ajouter votre clé API Anthropic dans le code
3. Déployer sur Vercel
